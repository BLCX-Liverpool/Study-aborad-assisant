# 谭成义健身知识库适配参考

来源：<https://github.com/Brave-Maker/tanchengyi-fitness>

本文件用于将外部 Skill 的训练哲学适配到 Study Abroad Assistant 的 Fitness Agent。运行时必须优先遵守项目 schema 和安全边界。

## 训练哲学

- 训练质量 > 训练重量：不要为了重量牺牲动作标准度。
- 意念-肌肉连接：通过视觉传导、注意力集中和慢速控制，让目标肌肉主导发力。
- 自然健美：循序渐进，重视长期可持续训练。
- 可成长性训练：根据个人能力选择动作模式，从当前能稳定完成的版本开始。
- 训练即拉伸：在安全范围内追求动作幅度、控制和目标肌肉感受。

## 跟练教程格式

生成动作说明时，优先使用：

- 动作名称。
- 组数 / 次数 / 时间。
- 动作细节。
- 发力感受。
- 常见错误。
- 保守调整方式。

示例：

- 哑铃杯式深蹲：3 组，每组 8-12 次。下蹲时保持躯干稳定，膝盖方向与脚尖一致，底部停顿 1 秒再起。常见错误是塌腰、膝盖内扣、为了蹲深牺牲控制。

## 新手计划原则

- 优先全身训练或简单推拉腿拆分。
- 每次 3-5 个主要动作即可。
- 每组保留 1-3 次余力。
- 先稳定完成动作，再增加重量、组数或训练密度。
- 学业压力大时，优先保留训练频率，减少容量。

## 进阶计划原则

- 可使用推 / 拉 / 腿三分化。
- 每周围绕主要肌群安排可恢复的容量。
- 使用 RPE 或主观余力控制强度。
- 渐进只增加一个变量：重量、次数、组数、动作幅度、节奏或休息时间。

## 推拉腿结构参考

推：胸、肩、三头。

- 推举或卧推动作。
- 上斜或肩部辅助推。
- 侧平举或肩部控制。
- 三头伸展或下压。

拉：背、后束、二头。

- 划船或下拉。
- 后束肩或面拉。
- 二头弯举。
- 核心稳定。

腿：股四头、臀腿后侧、小腿、核心。

- 深蹲模式。
- 髋铰链模式。
- 单腿动作。
- 小腿或核心。

## 居家 / 无器械调整

- 深蹲、分腿蹲、臀桥、俯卧撑、桌边划船、背包划船、死虫、平板支撑。
- 用慢速离心、底部停顿和缩短休息时间增加难度。
- 避免使用不稳定或危险的家具做高风险动作。

## 安全边界

- 不诊断疼痛原因。
- 不给康复处方。
- 不建议药物、补剂治疗或极端饮食。
- 有疼痛、眩晕、胸痛、麻木或异常症状时停止训练并寻求专业支持。
- 有伤病或医生建议时，训练计划必须保守，并提示先获得专业许可。
